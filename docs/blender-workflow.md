# Asset Workflow

> Status: historical Blender/Unity workflow preserved; active Godot GLB workflow implemented and CI-tested. Human visual sign-off and real-device verification are still pending.

## Active Godot GLB workflow

The active game is Godot 4 under ADR-0004. Its shipped visual assets are generated by `Tools/Blender/Scripts/generate_visual_glbs.py`, a deterministic pure-Python generator that writes 13 textured/animated GLB files into `godot/assets/models/`. It embeds procedural PNG textures and does not require Blender.

Regenerate with:

```sh
python3 Tools/Blender/Scripts/generate_visual_glbs.py
```

Structural validation covers GLB header/JSON/BIN chunks, bufferViews/accessors, indexes, materials, embedded PNG textures, animation channels, sampler counts, and bounds. Godot import, headless smoke, five-frame gameplay capture, and Android export passed in GitHub Actions. See `docs/visual-asset-inventory.md` for the asset list, bounds, triangle counts, and evidence.

## Historical Blender/Unity workflow

The preserved Unity project remains untouched as history. The older `Tools/Blender/Scripts/generate_assets.py` generated 11 OBJ/MTL model pairs; copies remain under `Assets/Resources/Art/Models/` and `godot/assets/models/` as fallback assets. No Unity scene, prefab, import, FBX/GLB export from desktop Blender, or Unity gameplay verification is claimed.

Historical source layout:

```text
Tools/Blender/
├─ Source/
│  ├─ Characters/
│  ├─ Trains/
│  ├─ Stations/
│  ├─ Props/
│  └─ Environments/
├─ Scripts/
│  ├─ export_fbx.py
│  ├─ export_glb.py
│  ├─ validate_scene.py
│  └─ naming_conventions.md
└─ Exports/
   ├─ Characters/
   ├─ Trains/
   ├─ Stations/
   ├─ Props/
   └─ Environments/
```

Historical naming conventions:

- Source: `ISR_<category>_<name>_<variant>.blend`
- Mesh: `SM_<category>_<name>_<variant>`
- Rig: `RIG_<category>_<name>`
- Animation: `AN_<character>_<action>`
- Material: `M_<surface>_<variant>`
- Texture: `T_<asset>_<map>` where map is `BC`, `N`, `RMA`, or `E`.

Historical scale and axes:

- 1 Blender unit = 1 metre.
- Character roots at feet.
- Props pivot at logical placement point.
- Apply transforms before export unless rig constraints require otherwise.
- Recalculate normals and remove unused materials before export.

## Current limitation

This shell has no Blender installation. The active visual work is therefore generated by the pure-Python GLB generator. The old Android Blender build had a broken FBX export operator, which is why the original generator wrote OBJ/MTL. Temporary primitive visuals have been replaced by authored GLBs in the Godot path, with fallbacks retained only for import failure tolerance.
